## FactQL

**The model writes a plausible answer. FactQL makes it true.**

FactQL sits between your AI app and your data. It runs the query before it answers, checks the answer against the rows, and declines instead of guessing. Every answer comes with its evidence: what it looked at, the rows it found and how it got there.

- **Bring your data:** PostgreSQL, MySQL, or a CSV / Excel upload
- **One API:** send a question, get the answer, the query that ran, the rows and the lineage
- **Built for agents:** use it as a tool from LangChain, LangGraph, OpenAI-style function calling, or embed a chat in any page
